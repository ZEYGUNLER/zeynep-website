# 🌿 Dijital Bahçe (Web)

## 📖 Proje Hakkında
"Dijital Bahçe", okuma deneyimini oyunlaştıran kişisel bir web platformudur. Kullanıcılar makaleleri okudukça profillerindeki bahçe çiçeklenir ve dijital bir kütüphane/bahçe oluştururlar.
